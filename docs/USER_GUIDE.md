# 映库使用手册

安装、源码启动和构建方式见 [README](../README.md)。容器挂载、反向代理和迁移见 [容器部署说明](../DEPLOYMENT.md)。

## 添加来源

打开「来源 → 添加来源」。来源是映库可以浏览和选择视频的目录。

| 来源 | 配置方法 |
| --- | --- |
| 本地目录 | 填写运行映库的电脑或服务器上的目录。容器里填写挂载后的路径，例如 `/media`。 |
| WebDAV | 填写 WebDAV 根地址，按服务要求提供用户名和密码，然后保存并连接。 |
| 百度网盘 | 由部署者先配置具有网盘和设备授权权限的应用 App Key、Secret Key，再用百度账号授权。 |
| 夸克网盘 | 获取登录二维码，在夸克 App 扫码确认，然后保存并连接。 |

### 百度网盘

1. 第一次配置时，在添加百度网盘来源的窗口展开「部署者设置：百度应用（仅需一次）」，填写自己的 App Key 和 Secret Key。容器也可在运行环境中设置 `YINGKU_BAIDU_CLIENT_ID` 和 `YINGKU_BAIDU_CLIENT_SECRET`。
2. 点击「登录并授权百度网盘」，用百度网盘 App 扫码，或打开官方授权页输入设备码。
3. 授权完成后填写要浏览的目录，例如 `/影视`，点击「保存并连接」。已有来源可在编辑时重新登录。

高级选项还支持使用授权码或已有的 Access Token、Refresh Token。应用权限和下载额度以百度账号实际授权为准。[百度网盘开放平台](https://yun.baidu.com/union/home)

### 夸克网盘

1. 点击「获取夸克登录二维码」，用夸克手机 App 扫码并确认。
2. 页面显示登录完成后，点击「保存并连接」。映库会检查目录并保存登录状态。
3. 默认从网盘根目录开始浏览。若只需要某个子目录，在「限制可浏览的目录」填写夸克网页地址中该目录的文件夹 ID。根目录 ID 为 `0`。

扫码使用夸克网页登录。登录过期时重新扫码，必要时可通过高级选项填写自己的网页登录 Cookie。账号的下载权限、网络和夸克网页接口都会影响连接与下载。

## 导入电影和电视剧

1. 打开来源中的目录，勾选想加入的视频并点击「导入所选」。如果目录包含多部作品或多季剧集，可以用「扫描整个目录」识别当前目录及子目录。
2. 核对名称、年份、类型和季集。年份可以留空，电视剧填写的是整部剧的首播年份。
3. 批量扫描时，从候选资料里确认正确作品，或者选择「暂不匹配，按当前名称入库」。文件名或 AI 识别的名称是供核对的建议，确认候选后才会绑定在线作品编号。
4. 单部导入点「预览文件与分集」，批量扫描点「检查导入预览」。检查季集、重复提示和保存位置，再确认入库。

本地视频默认原地入库，继续使用原文件。需要把视频统一存放时可选择复制整理。百度、夸克和 WebDAV 视频会进入下载任务，文件完成后可以播放。一次递归扫描最多处理 1000 个视频、1200 个目录和 20 层子目录，超出时可分目录导入。

遇到后续季时，可通过「所属剧集」追加到已有作品。同名且需要区分的作品可新建独立条目。无法识别的文件会出现在「待确认文件」，可多选并批量归入同一部剧，再核对集号。特别篇用季数 `0`，例如 `S00E01` 或 `SP01`。合并了多集的单个视频可填写起止集号。

### 可选的 AI 文件识别

在「设置 → AI 文件识别」填写端点、模型和所需的 API Key，保存后可测试连接。端点可填写兼容服务的 `/v1` 基础地址或完整的 `/chat/completions` 地址。随后扫描目录时选择 AI 识别。

每批最多识别 80 个视频。模型接收所选目录名、视频相对路径和文件编号，用于推测剧名、季数与集数。识别有误时，可以点「用 AI 重新识别」，写明正确作品或编号规则，再核对新结果。调用失败会保留原识别结果。未提交的扫描结果在服务重启后需要重新生成。

### 作品资料

映库优先读取本地已有的 NFO 和海报，并可用维基百科、Wikidata 与 TVmaze 补齐资料。默认检索公开资料无需 API Key。配置自己的 TMDb Key 或 API Read Access Token 后，检索优先使用 TMDb。作品详情会标注资料来源和许可提示。

如果匹配错了，可以进入作品详情的「更多作品操作 → 匹配作品」重新选择。需要更新现有作品的资料时使用「补全资料」，视频文件会继续沿用当前记录。

## 下载任务与文件管理

- 「下载任务」支持按作品、文件名和状态筛选，也可以多选后暂停、继续、取消或移除任务记录。取消后保留临时文件，可再次继续。已完成的任务记录可以单独清理。
- 可从媒体库移出电影、整部剧、某季或某个视频。默认保留磁盘文件。勾选「同时永久删除服务器上的视频文件」后，应核对清单再确认。本地来源会删除列出的原视频，网盘来源会删除列出的本机下载文件。网盘上的原文件会保留。
- 移除本地来源也会移除来自该来源的媒体库记录，磁盘视频仍然保留。移除网盘或 WebDAV 连接会保留已下载的视频和对应入库记录。
- 出现「文件不可用」时，先检查磁盘或 NAS 是否已挂载。如果视频已经移动，可选择「重新定位」，填写新路径以保留该条目的资料和观看进度。容器内填写映库能访问的容器路径。

## 播放与字幕

从海报墙打开作品或从「继续观看」续播。电视剧可以切换上下集，并在播放器设置里开启或关闭自动连播。

| 操作 | 用法 |
| --- | --- |
| 暂停与全屏 | 空格或 K 播放／暂停，F 切换全屏，M 静音。 |
| 调整进度 | 方向键左右各跳 5 秒。播放中长按右方向键可临时倍速。触屏可左右滑动调整进度。 |
| 调整声音和亮度 | 上下方向键调音量。触屏在右半区上下滑动调音量，在左半区上下滑动调画面亮度。 |
| 添加字幕 | 使用播放器的「添加字幕」或作品详情里的「文件与字幕」，添加 UTF-8 编码的 SRT 或 VTT，再在播放设置里选择。 |

映库也会在本地导入时收集同名 SRT / VTT 字幕。浏览器直接解码视频和音轨，MP4 / H.264 / AAC 通常更容易播放。其他编码与容器的支持取决于设备与浏览器。当前没有实时转码，ASS / PGS 特效字幕也不在支持范围。

## 手机访问与电视投屏

1. 手机和服务器连接同一局域网。在「设置 → 手机访问与 DLNA 投屏」找到访问地址，从手机浏览器打开。
2. 让电视开启 DLNA 接收功能，打开影片后点击播放器顶部的投屏按钮，选择电视。
3. 在「电视遥控」控制播放、暂停、进度和上下集。音量、电视遥控器控制和自然结束后的自动连播取决于电视接收器。网页返回播放器时会同步电视能报告的进度。

找不到电视时，检查服务器与电视是否在同一网络，以及电视、系统防火墙和容器网络是否允许 DLNA 发现。电视能找到但无法播放时，可检查视频编码和「投屏回连地址」。容器网络相关设置见 [容器部署说明](../DEPLOYMENT.md#dlna-与容器网络)。

默认服务监听 `0.0.0.0:8787`。局域网网页访问密码可在服务所在电脑上设置。免登录时，能访问服务的设备也可以管理媒体库。

## 数据和备份

普通启动的数据目录默认为 `data/`，镜像内默认为 `/config`。可以通过 `-data` 或 `YINGKU_DATA_DIR` 更改数据目录。配置、观看进度、海报缓存和添加的字幕保存在这里，下载目录可单独指定。

备份时停止服务，复制完整的数据目录，确保 `state.json` 和 `secret.key` 一同保存。原地入库的视频以及保存在其他目录的下载文件需要单独备份。更新镜像时继续使用原有持久挂载。一份数据目录只由一个映库实例使用。涉及凭据或个人媒体库记录的数据目录应保存在本地备份中。
